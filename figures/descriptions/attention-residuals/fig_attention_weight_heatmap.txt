Learned Depth-Wise Attention Weight Heatmap from a Trained Model

IMPORTANT: Pure white background (#FFFFFF). No gray tint, no gradient.

== CONTEXT ==
This visualizes the attention weights that a trained model learns for depth-wise aggregation. The heatmap shows which source layers each target layer attends to. Notable patterns emerge: early layers attend to embeddings, middle layers to nearby predecessors, deep layers develop long-range connections.

== LAYOUT ==
- A square heatmap grid
- X-axis: source layers (0 to 7, representing 8 blocks)
- Y-axis: target layers (1 to 8, which block attends to what)
- Color intensity shows attention weight magnitude

== COMPONENTS ==
1. Heatmap grid (8x8 or similar)
   - X-axis label: "Source Block"
   - Y-axis label: "Target Block"
   - Color scale: white (0.0) to deep blue #1a5276 (1.0)
   - Grid lines: light gray

2. Attention patterns to show:
   - Block 1 row: strong weight on embeddings (column 0), weak elsewhere
   - Block 2 row: moderate on embeddings, strong on Block 1
   - Block 3 row: weak on embeddings, moderate on Block 1-2
   - Block 4 row: spread across Block 1-3
   - Block 5-6 rows: focused on Block 3-4 (nearby)
   - Block 7-8 rows: interesting pattern with both nearby AND distant (Block 1-2) connections
   - Diagonal pattern should be visible (nearby blocks get more weight)

3. Color bar legend (right side)
   - Gradient from white to deep blue
   - Labels: "0.0 (no attention)" to "1.0 (full attention)"

4. Three annotation callouts:
   - Arrow to top-left corner: "Early blocks attend to embeddings"
   - Arrow to diagonal: "Nearby blocks get high weight"
   - Arrow to bottom-left: "Deep blocks also attend to early layers (long-range)"

5. Title: "Block AttnRes: Learned Attention Weights (Kimi Linear 48B)"
