The Residual Stream in a Standard Transformer

IMPORTANT: Pure white background (#FFFFFF). No gray tint, no gradient.

== CONTEXT ==
This diagram shows how residual connections work in a standard PreNorm transformer. A vertical "residual stream" runs from bottom to top, and each layer adds its output to this stream with a fixed weight of 1.0. The stream grows larger at each layer.

== LAYOUT ==
- Direction: bottom-to-top (input at bottom, output at top)
- Central vertical thick line representing the "residual stream"
- 6 layers branching off to the right, each feeding back into the stream
- The residual stream line should get progressively thicker/bolder going up to visually represent magnitude growth

- Each layer block has an arrow going right from the stream (taking input) and an arrow returning left to the "+" merge point
- Labels on each merge: "+1.0" to emphasize fixed unit weight
- The stream after each merge should be visually thicker than before
