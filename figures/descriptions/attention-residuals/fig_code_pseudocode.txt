== CONTEXT ==
This figure shows the official PyTorch pseudocode for Block AttnRes with visual annotations explaining each step. The code stacks previous block representations, normalizes with RMSNorm, computes attention logits via einsum, applies softmax, and produces the weighted aggregation.

1. Code block (left, ~60% width)
   - Dark background #2D2D2D or #1E1E1E (code editor style)
   - White/colored text for syntax highlighting
   - Python code:
     ```
     def block_attn_res(block_reprs, partial_sum, proj):
         # Step 1: Stack all sources
         V = stack(block_reprs + [partial_sum])

         # Step 2: Normalize
         V = RMSNorm(V)

         # Step 3: Compute attention logits
         logits = einsum('d, n b t d -> n b t',
                         proj.weight.squeeze(), V)

         # Step 4: Softmax over block dimension
         weights = logits.softmax(dim=0)

         # Step 5: Weighted aggregation
         output = einsum('n b t, n b t d -> b t d',
                         weights, V)
         return output
     ```
