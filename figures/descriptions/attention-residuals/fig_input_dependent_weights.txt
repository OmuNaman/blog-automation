Input-Dependent Attention Weights: Different Tokens, Different Layer Preferences

IMPORTANT: Pure white background (#FFFFFF). No gray tint, no gradient.

== CONTEXT ==
This diagram demonstrates that different tokens produce different attention weight distributions over previous layers. The same pseudo-query w_l produces different weights because the keys (derived from layer outputs) depend on the input token. This is the key advantage over fixed-weight approaches.

== LAYOUT ==
- Direction: left-to-right, showing 3 different tokens' weight distributions side by side
- Each column shows one token's attention weights at layer 4
- A shared set of source layers on the left
