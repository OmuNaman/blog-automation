Step 2: The Window Distance Mask

This diagram shows the window distance constraint mask as an 8x8 grid matrix. This is step 2 of the 3-step mask construction process.

HEADER:
- Title: "Step 2: Window Mask (w = 3)" in bold at the top.
- Subtitle: "Rule: token i can attend to token j only if i - j < w (distance < 3)"

THE MATRIX:
- An 8x8 grid of cells.
- Row labels on the left: 0, 1, 2, 3, 4, 5, 6, 7.
- Column labels on top: 0, 1, 2, 3, 4, 5, 6, 7.
- Left axis label: "Query position (i)".
- Top axis label: "Key position (j)".

CELL VALUES AND COLORS:
- Cells where |i - j| < 3 (within window distance): value "1", filled with pastel green.
- Cells where |i - j| >= 3 (outside window): value "0", filled with light red or pink.
