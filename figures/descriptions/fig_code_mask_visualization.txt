Visualization of the PyTorch SWA Mask Output

IMPORTANT: Pure white background (#FFFFFF). No gray tint, no colored background, no gradient. The diagram must have a clean white background suitable for an academic paper/blog post.

This diagram shows the attention mask matrix that would be produced by the PyTorch code implementation, connecting the code to the visual result. Layout is two parts: code snippet on the left, resulting matrix on the right.

LEFT SIDE - "Code":
- A code block with a light gray background (like a code editor), showing the key lines:

  mask = (col <= row) & (row - col < w)

  where w = 3

- Use a monospace font. The code should be clearly readable.
- Syntax highlighting: keywords in blue, variables in black, numbers in red.

- A large right-pointing arrow labeled "Produces" connecting code to matrix.
